# Manga Library Scanner

만화 라이브러리를 스캔하고 정리하기 위한 Windows용 유틸리티입니다.

## 다운로드

- 최신 배포 파일은 [GitHub Releases](https://github.com/Kuumma26/Manga-Library-Scanner/releases)에서 받을 수 있습니다.
- 저장소 본문에는 exe를 보관하지 않고, 실제 배포 파일은 Releases에서만 제공합니다.

## 버전 정보

- 최신 버전 정보는 `version.json`에 정리되어 있습니다.
- 실제 exe 배포는 GitHub Releases 기준으로 관리합니다.

## 참고

- 이 저장소는 배포 파일과 버전 정보를 관리하기 위한 용도로 사용합니다.
- 자세한 변경점은 각 릴리즈 노트에서 확인할 수 있습니다.
