Manga Library Scanner는 ZIP, CBZ, RAR, CBR, PDF 같은 만화 파일을 스캔해 시리즈별 목록으로 정리하고, 검색, 중복/누락 확인, 이미지 해상도 분석, 보유 목록 비교를 도와주는 프로그램입니다.

## 주요 기능

- 폴더 스캔: 로컬 드라이브와 NAS/SMB 공유 폴더의 만화 파일을 시리즈 단위로 정리합니다.
- 빠른 검색: 제목, 파일명, 경로를 기준으로 라이브러리에서 원하는 작품을 찾습니다.
- 중복/누락 체크: 같은 권이 여러 개 있거나 중간 권수가 빠진 작품을 쉽게 확인합니다.
- 목록 검사: 게시글 목록이나 구매 예정 목록을 붙여넣어 보유 중, 부분 보유, 미보유, 제외 항목으로 나눠 확인합니다.
- 이미지 해상도 분석: 압축 파일 안의 이미지 크기와 품질 정보를 확인합니다.
- 통합 비교: 두 폴더나 파일 묶음을 좌우로 비교해 차이를 확인합니다.
- 자동 업데이트: 새 버전이 있으면 프로그램 안에서 업데이트를 진행할 수 있습니다.
- 피드백 보내기: 프로그램 안에서 버그나 개선 요청을 바로 보낼 수 있습니다.

## 처음 사용하는 방법

1. 최신 버전 다운로드

   [최신 릴리즈](https://github.com/Kuumma26/Manga-Library-Scanner/releases/latest)에서 `Manga.Library.Scanner.vX.Y.Z.exe` 파일을 내려받습니다.

2. 원하는 위치에 넣고 실행

   별도 설치 과정은 없습니다. 예를 들어 `만화 라이브러리 스캐너` 같은 폴더를 만들고 exe 파일을 넣은 뒤 실행하면 됩니다.

3. 스캔할 폴더 추가

   프로그램 상단의 `폴더 추가` 버튼으로 만화 파일이 들어 있는 폴더를 추가합니다. NAS 경로도 Windows에서 접근 가능한 공유 경로라면 사용할 수 있습니다.

4. 폴더 스캔 시작

   `폴더 스캔 시작`을 누르면 체크된 경로를 스캔합니다. 처음 스캔은 파일 수에 따라 시간이 걸릴 수 있고, 이후에는 저장된 목록과 캐시를 사용해 더 빠르게 불러옵니다.

5. 검색과 확인

   스캔이 끝나면 통합 검색창으로 작품을 찾고, 중복 체크나 누락 체크를 켜서 정리할 항목을 확인합니다.

6. 환경설정 조정

   `환경 설정`에서 스캔 확장자, 최소 파일 크기, 목록 줄 높이, 테마, 키워드, 해상도 기준, 단축키 등을 조정할 수 있습니다.

## 기본 조작

- 더블클릭: 선택한 파일이나 폴더 위치를 엽니다.
- 우클릭: 개별 분석을 실행합니다.
- Shift+우클릭: 개별 분석, 통합 비교, 리디 검색 같은 메뉴를 엽니다.
- Ctrl+우클릭: 통합 비교 왼쪽에 추가합니다.
- Ctrl+Shift+우클릭: 통합 비교 오른쪽에 추가합니다.
- 마우스 올림: 긴 제목이나 파일명을 툴팁으로 확인합니다.
- Shift+마우스 올림: 설정에 따라 표지 미리보기나 긴 제목 툴팁을 우선 표시합니다.

## 목록 검사 사용법

목록 검사는 게시글 제목이나 구매 예정 목록을 여러 줄로 붙여넣고, 현재 라이브러리에 있는지 비교하는 기능입니다.

- `보유 중`: 요청한 범위를 모두 가지고 있는 항목입니다.
- `부분 보유`: 일부 권수만 가지고 있거나 범위가 부족한 항목입니다.
- `미보유`: 라이브러리에서 매칭되는 작품을 찾지 못한 항목입니다.
- `제외`: 사용자가 지정한 제외 키워드에 걸린 항목입니다.

BL, 순정처럼 검사 결과에서 따로 보고 싶은 분류는 환경설정의 키워드 탭이나 목록 검사 창의 제외 키워드 편집에서 조정할 수 있습니다.

## 이미지 해상도 분석

개별 분석과 통합 비교에서는 압축 파일 안의 이미지 해상도, 파일 수, 폴더 구조를 확인할 수 있습니다.

- ZIP/CBZ는 내부 파일을 직접 검사합니다.
- RAR/CBR은 PC 환경에 따라 추가 압축 해제 도구가 필요할 수 있습니다.
- PDF는 파일에서 얻을 수 있는 페이지 크기 정보를 기준으로 표시합니다.
- 같은 파일을 반복 분석할 때는 캐시를 사용해 더 빠르게 결과를 보여줍니다.

## 자동 업데이트

프로그램은 GitHub 릴리즈 정보를 확인해 새 버전이 있으면 업데이트 버튼을 표시합니다.

- 자동 업데이트가 실패하면 수동 다운로드 버튼으로 브라우저 다운로드를 진행할 수 있습니다.
- 일부 PC에서 인증서나 네트워크 환경 때문에 자동 다운로드가 막힐 수 있습니다.
- 업데이트 후에는 새 버전에서 변경된 패치노트가 표시됩니다.

## 피드백 보내기

프로그램 안의 `피드백` 버튼으로 버그나 개선 요청을 보낼 수 있습니다.

가능하면 아래 내용을 함께 적어주시면 문제를 재현하고 고치기 쉽습니다.

- 어떤 화면에서 발생했는지
- 어떤 입력값이나 파일명에서 발생했는지
- 기대한 결과와 실제 결과가 어떻게 다른지
- 가능하면 문제가 되는 예시 제목이나 파일명

## 문제 해결

- 스캔 결과가 이상하면 먼저 스캔 경로가 체크되어 있는지 확인해 주세요.
- NAS 경로가 일시적으로 끊긴 경우, 네트워크 연결을 확인한 뒤 다시 스캔해 주세요.
- 목록 검사 결과가 이상하면 예시 제목과 실제 소장 파일명을 함께 피드백으로 보내 주세요.
- RAR/CBR 분석에서 `RarCannotExec` 오류가 나오면 RAR 분석에 필요한 도구가 PC에 없거나 실행되지 않는 상태일 수 있습니다.
- 설정을 크게 바꾼 뒤 결과가 이상하면 캐시 비우기 후 다시 스캔해 보세요.

## 시스템 요구사항

- Windows 10 또는 Windows 11 64-bit
- 로컬 드라이브 또는 Windows에서 접근 가능한 NAS/SMB 공유 폴더
- 자동 업데이트와 피드백 전송에는 인터넷 연결 필요
